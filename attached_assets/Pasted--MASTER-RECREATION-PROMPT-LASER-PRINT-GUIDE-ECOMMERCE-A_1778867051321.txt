## 2. BACKEND API SPECIFICATION
**Base URL:** `https://api.inklivo.shop/public`

### Endpoints:
1.  **GET `/categories`**: Returns nested category objects (`id`, `name`, `slug`, `children[]`).
2.  **GET `/brands`**: Returns brand list (`id`, `name`, `slug`).
3.  **GET `/products?limit=1000`**: Returns all products.
    - Fields: `id`, `name`, `slug`, `price`, `original_price`, `description`, `images` (JSON/Array), `category_id`, `category_slug`, `brand_name`.
4.  **GET `/products/{slug}`**: Single product details.
5.  **POST `/orders`**: Place order. Payload: `{ email, firstName, lastName, address, city, zipCode, phone, paymentMethod, total, items[], payment_details }`.
6.  **POST `/newsletter`**: Newsletter subscription. Payload: `{ email }`.
7.  **POST `/contacts`**: Contact form. Payload: `{ name, email, phone, subject, message }`.
8.  **Admin Stats:** `GET /admin/stats` (Requires Bearer Token).

## 3. CORE LOGIC & FILTERING RULES (STRICT)

### Data Filtering (Catalog Scope)
- **Exclude Categories:** Filter out any category related to "Laptops", "Computers", "PCs", or "Notebooks".
- **Exclude Products:** Do NOT display products that contain "laptop", "macbook", "notebook", "chromebook" in their name.
- **Brand Exclusions:** Filter out brands like "Brother" and "Xerox". 
- **Showcase Focus:** Featured sections should ONLY focus on: **HP, Canon, Epson, and Lexmark**.
- **Prohibited Labels:** Do NOT use terms like "Authorized Dealer" or "Expert Support" anywhere in the UI. Focus on being a "Product Guide".

### GlobalContext.jsx Logic
- Fetch Categories and first 20 Products on mount. (Do NOT call the `/brands` API).
- **Strict Filtering:** Apply the filters above before setting state.
- Background-fetch remaining products (limit=1000) with same filters.

### CartContext.jsx Logic
- Handle `addToCart`, `removeFromCart`, `toggleWishlist`.
- Persist state in `localStorage`.
- Provide `cartCount` and `cartTotal`.
